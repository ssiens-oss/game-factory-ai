# ECHO//LIFE — Prototype Systems

## Run state
A new survivor starts with:
- 72 hours remaining
- Health: 100
- Energy: 100
- Cash: $40
- Backpack capacity: 8
- Random personal problem
- Unknown Collapse scenario

## Behavioral fingerprint
Six hidden values start at 0 and change through actions:
- Empathy
- Aggression
- Greed
- Courage
- Deception
- Curiosity

Values are not shown as morality scores. The game describes patterns indirectly through NPC reactions, rumors, dreams, and eventually the Echo.

## Example encounter
A stranger is trapped behind a jammed apartment door while smoke spreads through the hall.

Choices can include:
- Help them: costs time/energy; raises empathy/courage.
- Demand payment: may earn cash; raises greed.
- Search their abandoned bag: gains loot; raises greed/deception.
- Leave: preserves resources and becomes part of the behavioral history.

There is no guaranteed best choice. The Collapse and later consequences can change the value of each decision.

## Echo generation
At run end, generate an EchoProfile containing:
- dominant behaviors
- favored item categories
- common encounter strategy
- accumulated skills
- important relationships
- notable betrayals/help given
- preferred escape route
- final equipment
- cause/outcome of the run

Future runs can instantiate that profile as an NPC or antagonist.

## First Collapse
BLACKOUT: citywide power and communications failure. Water pressure declines, stores close, traffic locks up, and factions begin forming. Clues before the event allow the player to prepare batteries, water, tools, food, transportation, and allies.

## Expansion scenarios
- Flash freeze
- Machine failure
- Economic crash
- Disappearance event
- Contaminated water
- Reality anomaly

## Prototype victory
Survive the first 24 hours after the Collapse and reach a secure shelter.

## Long-term hook
Every completed or failed run adds history to the city. Eventually the player's own previous characters become some of the world's most important NPCs.
