# ECHO//LIFE v45 — Thousand Lights

100 implemented improvements are listed in [IMPROVEMENTS.md](IMPROVEMENTS.md). v44 and every archived build are preserved.

Ten puzzle families: circuits, Lights Out, signal ordering, frequency dials, sliding tiles, memory pairs, weighted balance, coupled mosaics, combination locks, and 4×4 mazes. Puzzles pause the world and offer free hints, undo/redo, explanations and optional move-efficiency stars. No puzzle has a deadline. Practice and UTC daily boards never grant run rewards.

Explore the atlas, return to restored relays, collect memories and caches, heal at fountains, speak to residents, and earn restoration honours. Peaceful exploration is the default. Disable it in Display + Controls to re-enable the preserved light patrol combat. Weapons, upgrades, medkits, touch controls, gamepad play and transparent HUD remain available.

Controls: WASD/arrows or joystick move; F interacts (remappable to G or Enter); M opens the atlas; P opens practice; J opens notes. Puzzle number keys 1–9 choose tiles; arrows navigate or move in a maze; Z undoes, Y redoes, H hints. Escape returns. Gamepad D-pad navigates dialog buttons; A activates; B returns; bumpers undo/hint.

Autosaves use a versioned checksum envelope and a valid backup. Save Now, Export Run and Import Run are in the pause screen. Continue resumes a valid v45 run. Import v44 Exploration preserves its rewards and starts the corresponding v45 relay puzzle. Combat encounters restart after loading. Saves include exploration collections, achievements, puzzle state and bounded undo/redo history. Storage denial is nonfatal; exported files remain usable. Import requires a valid v45 save no larger than 64 KiB.

Accessibility preferences include large text, high contrast, reduced decoration, adjustable movement sensitivity, optional haptics, simple touch layout and quality selection. Search and filter journal memories by text and family.
